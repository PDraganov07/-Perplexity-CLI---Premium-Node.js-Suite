# ⚡ Perplexity CLI - Premium Node.js Suite

A modern, high-performance Command Line Interface for the Perplexity AI API. Built with a focus on speed, aesthetics, and user experience.


## ✨ Key Features

- **Premium UI/UX**: Stunning terminal interface with gradients, custom boxes, and smooth animations.
- **Universal Model Support**: Switch instantly between `sonar-pro`, `sonar-deep-research`, and more.
- **Multi-Search Modes**: Optimize your results with `web`, `academic`, or `sec` search scopes.
- **Persistent Memory**: Full conversation history support for natural, contextual chat.
- **Safe API Storage**: Your API keys are encrypted and stored securely on your machine.
- **Markdown Perfection**: Beautifully rendered AI responses with full syntax highlighting.

## 🚀 Installation

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or higher recommended)

### Setup
1. Clone the repository:
   ```bash
   git clone https://github.com/PDraganov07/Perplexity-API---Complete-GUI-Suite
   cd "peplexity CLI"
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Launch the CLI:
   ```bash
   node index.js
   ```

## 📖 Commands

| Command | Description |
|---------|-------------|
| `/model` | Open interactive model selector |
| `/mode`  | Change search context (Web/Academic/SEC) |
| `/clear` | Wipe conversation history and clear screen |
| `/gui`   | Access the Graphical Interface version |
| `/help`  | Show the detailed command menu |
| `/exit`  | Terminate the application |

## 🛠️ Configuration

On the first run, the CLI will prompt you to enter your **Perplexity API Key**. 
- The key is saved locally in your user profile.
- You can also export it as an environment variable: `export PERPLEXITY_API_KEY=your_key_here`
